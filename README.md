# FORMA — Spaces designed for living

Многостраничный концептуальный сайт студии дизайна интерьеров и ремонта в Барселоне. Интерфейс на английском. Компания и проекты вымышлены, изображения не выдаются за выполненные заказы.

## ChatGPT Sites

В репозитории находится Next.js-проект для локальной разработки и Vercel с актуальным дизайном опубликованного сайта. Отдельная служебная копия для ChatGPT Sites хранится локально в `sites/forma/` и исключена из Git вместе с архивами публикаций. Подробнее о текущей публикации — [docs/SITES.md](docs/SITES.md).

Публичный адрес сборки: https://forma-interior-studio.wirybream10.chatgpt.site (доступ определяется настройками Sites).

## Локальный запуск

Требуется Node.js 22.9+ (рекомендуется актуальный Node.js 22 LTS) и npm.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Никакие ключи API или backend не нужны. Фото и шрифты находятся локально; сайт не обращается к Unsplash или Google Fonts при просмотре.

Production-сборка и локальный просмотр:

```bash
npm run build
npm start
```

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Браузерные проверки Playwright запускаются против уже работающего dev- или production-сервера:

```bash
npx playwright install chromium
npm run test:e2e
```

На macOS автоматически используется установленный Google Chrome, если он доступен. Другой браузерный executable можно указать через `PLAYWRIGHT_CHROME_EXECUTABLE`. Другой адрес сайта — через `PLAYWRIGHT_BASE_URL`.

Покрытие: все 13 страниц и фотографии, фильтры всех категорий, Before / After с клавиатурой и мышью, граничные значения площади, синхронизация ползунка и поля, сохранение выбора, скачивание файла расчёта, перенос параметров в форму, обязательные поля и email, завершение демо и копирование, мобильное меню, отсутствие горизонтального переполнения на 375/768/1440 px, автоматические WCAG-проверки и 404. Снимки страниц сохраняются в `test-results/`.

Семь unit-тестов проверяют формулу, все ставки и типы недвижимости, все допуслуги, границы площади, некорректные параметры, query roundtrip и текст скачиваемой сметы. Контрольный пример: `75 × 600 + 75 × 65 + 6000 = €55,875`.

Подробные результаты и границы проверки: [docs/QA.md](docs/QA.md).

## Архитектура

- `app/` — App Router: главная, Projects, 6 страниц проектов, Services, About, Contact, Estimate, Credits; metadata, loading, error, 404.
- `components/` — общая навигация, footer, редакционные секции, Motion, портфолио, сравнение, калькулятор, многошаговая форма.
- `lib/projects.ts` — весь контент проектов и услуг.
- `lib/estimate.ts` — ставки, типы, чистая функция расчёта, безопасный разбор URL, экспорт сметы.
- `app/globals.css` — Tailwind v4, токены, адаптивные композиции, интерактивные состояния и reduced motion.
- `public/images/` — локальные интерьерные фотографии и отдельные изображения Before / After, предоставленные владельцем проекта.
- `tests/` — unit- и браузерные тесты.

Стек: Next.js 16.4.2, React 19.3.1, TypeScript, Tailwind CSS 4, Motion, Lucide. Для формы, FAQ, ползунков и кнопок используются доступные HTML-элементы с собственным оформлением; сторонняя UI-библиотека здесь не требуется.

## Функциональность

Калькулятор: 5 шагов, площадь 25–250 м² целым числом, Basic €350/м², Standard €600/м², Premium €950/м². Design +€65/м², Kitchen +€6,000, Bathroom +€4,000, Smart Home +€2,500. Тип недвижимости не добавляет коэффициент. Дополнительные налоги, сборы и наценки не учитываются. Скачивание создаёт настоящий `.txt` файл со всеми строками расчёта и предупреждением о демонстрационных ценах.

Request Consultation передаёт только настройки калькулятора в query string. Форма подставляет тип, бюджет, описание и показывает подробную калькуляцию. Личные данные остаются в памяти страницы, не сохраняются в localStorage и не отправляются на сервер. Завершение показывает явно обозначенный preview и кнопку копирования. При перезагрузке данные формы очищаются.

Before / After использует два отдельных изображения владельца проекта 1672×941. Исходные PNG сохранены побайтно без изменений; lossless WebP проходит проверку пиксельного совпадения. Кадрирование, растягивание, ретушь и ImageGen не используются. Сторонний референс не выдаётся за работу FORMA. Управление мышью, touch, стрелками и Home/End сохранено.

## Публикация на Vercel

1. Поместите репозиторий в свой GitHub/GitLab/Bitbucket.
2. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
3. Framework Preset: **Next.js**. Root Directory: корень проекта. Install Command: `npm ci`. Build Command: `npm run build`. Output Directory оставьте стандартной.
4. Используйте Node.js 22.x. Переменные окружения не обязательны. Для собственного домена задайте `NEXT_PUBLIC_SITE_URL=https://your-domain.example` и выполните redeploy; иначе используется production URL Vercel.
5. Нажмите **Deploy**. Vercel обслуживает Next Image и все маршруты без дополнительной настройки.

Альтернативно из корня проекта: `npx vercel` для preview, затем `npx vercel --prod` для production (нужен ваш вход в Vercel). Репозиторий использует стандартную сборку Next.js; отдельная версия для Sites использует статический экспорт.

По умолчанию задан `robots: { index: false, follow: true }`, поскольку это демонстрационная компания. Перед публикацией в составе индексируемого портфолио можно изменить это в `app/layout.tsx`. Не добавляйте вымышленные отзывы, адреса и подтверждения реального опыта. Для настоящей студии потребуется отдельно согласованный backend и реальная обработка заявок.

Текущий дизайн: прежняя палитра bone/terracotta, крупные заголовки Space Grotesk и Inter. Основные стили — app/globals.css, фотографическая атмосфера и текущая геометрия сравнения — app/atmosphere.css. Редакционная тема из docs/DESIGN-EDITORIAL.md больше не активна. На главной добавлена фотополоса InteriorAtmosphere: существующие лицензированные референсы villa и bathroom, спокойное движение основного кадра на 36px за весь проход прокрутки, статичное изображение при reduced motion. Before / After сохранён без изменений.
