# Current comparison assets

The current comparison uses two separate 1672×941 PNGs supplied by the project owner. No AI edits or image-generation prompt are used in this revision.

The originals are copied byte-for-byte to public/images/comparison-before.png and comparison-after.png. The script scripts/prepare-comparison.mjs creates lossless WebP and asserts decoded-pixel equality for each image. There is no crop, rescale, sharpening or perspective correction. Both layers have identical native dimensions and are shown at their native aspect ratio.

Earlier text-removal prompts in Git history refer only to retired diptychs.
