# Current Before / After pair

Two separate PNGs supplied by the project owner:

- Before: Уютная скандинавская гостиная с видом из окон.png
- After: Уютная гостиная с каменным столиком.png
- Both originals are 1672×941, sRGB, no alpha.
- Preserved byte-for-byte as public/images/comparison-before.png and comparison-after.png.
- No ImageGen, retouching, registration, cropping, resizing, sharpening or new compression is applied to those PNGs.
- scripts/prepare-comparison.mjs creates lossless comparison-before-scandi.webp and comparison-after-scandi.webp and verifies decoded-pixel equality to each original PNG.
- The comparison uses both full frames at their original ratio; it is capped at 1200 CSS pixels and scales down responsively.
- Original photographer, publication and documentary provenance were not supplied; no Creative Commons license or FORMA authorship is claimed.

Historical kitchen/living-room assets remain archived but are no longer displayed.
